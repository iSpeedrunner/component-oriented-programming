# Лабораторна робота №2 — World Bank Dashboard

React-дашборд для завантаження та відображення реальних економічних даних із World Bank API.

## Реалізовано

- завантаження даних через `useEffect`
- збереження даних у `useState`
- стани `loading`, `error` та `empty`
- таблиця з даними по країнах
- сортування за назвою країни та населенням
- KPI-картки на основі реальних даних
- розділення API-логіки та UI-компонентів

## Дані

Використовуються показники World Bank:

- населення
- ВВП
- очікувана тривалість життя
- рівень безробіття
