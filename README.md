# World Bank Dashboard — ЛР5

React-застосунок для перегляду економічних показників країн та економік із World Bank API. Лабораторна робота з компонентно-орієнтованого програмування.

## Технології

JavaScript, React, Vite, React Router, Redux Toolkit, React Redux, React Hook Form і Recharts. Перевірки виконують ESLint і вбудований тестовий модуль Node.js.

## Функціональність

- На дашборді `/` доступні пошук країни з debounce 400 мс, фільтри за регіоном і рівнем доходу та скидання фільтрів.
- KPI показують сумарні ВВП і населення та середню тривалість життя для відфільтрованих записів. Таблиця підтримує сортування, пагінацію й перехід до профілю `/country/:code`.
- Favorites доступні в таблиці та профілі. Обидві кнопки показують той самий стан за кодом країни World Bank.
- Recharts відображає розподіл за рівнем доходу. Перемикач **Bar chart / Pie chart** змінює вигляд того самого розподілу. Графіки використовують повну завантажену вибірку після фільтрації, незалежно від сторінки таблиці.
- Інтерфейс має світлу й темну теми та стани завантаження, помилки й порожнього результату. Профіль окремо повідомляє про неіснуючу країну.

## Глобальний стан

`src/store/store.js` створює Redux store через `configureStore`. `Provider` у `src/main.jsx` надає store застосунку.

| Slice | Дані |
| --- | --- |
| `filters` | Текст пошуку, регіон, рівень доходу. |
| `theme` | Поточна світла або темна тема. |
| `favorites` | Коди обраних країн. |
| `chart` | Тип графіка `bar` або `pie`. |

Компоненти читають стан через селектори й оновлюють його через `dispatch`. Дані запитів, сортування та пагінація мають локальний стан.

## Запуск і перевірки

Використовуйте Node.js 24 і npm. Проєкт перевірено на Node.js 24.21.0.

```sh
npm ci
npm run dev
```

Відкрийте локальну адресу, яку виведе Vite.

```sh
npm run lint
npm run build
npm test
```

## Дані й обмеження

- Застосунок завантажує каталог країн та останні доступні значення ВВП, населення й тривалості життя з [World Bank API v2](https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures). Рік останнього спостереження може різнитися між країнами й показниками.
- Сервіс читає першу сторінку кожного запиту з `per_page=400`. Розподіл охоплює завантажені країни, які відповідають фільтрам і мають категорію доходу. Агрегати World Bank виключаються.
- Якщо збій обмежений модулем одного графіка, для відновлення можна вибрати інший тип. Дія **Reload page** перезапускає застосунок. Після повного перезавантаження фільтри, тема, Favorites і тип графіка повертаються до початкового стану.
